# Codex Global Instructions

Read and follow `AI_RULES.md` before working. Apply any nearer project `AGENTS.md` instructions as well; project-local instructions take precedence when they conflict.

## Codex-specific defaults

- Use skills only when their trigger matches the task.
- Before a non-trivial code change, state the planned files, approach, risks, and verification command; wait for explicit approval.
- For small, reversible, well-scoped fixes, proceed and report the actual verification result.
- Keep user-authored files unchanged unless the request requires editing them.
