DAY 1: THIẾT LẬP CƠ SỞ DỮ LIỆU TƯỚNG VÀ PHƯƠNG PHÁP KIỂM CHỨNG (SANGO HEROES 7)

1. TẠI SAO CẦN LẬP BẢNG DỮ LIỆU CÓ NGUỒN TRÍCH XUẤT?

Trong Tam Quốc Quần Anh Truyện VII (Sango Heroes 7), các thông số tướng (Vũ lực, Trí lực, Võ tướng kỹ, Quân sư kỹ) và điều kiện thu phục/xuất hiện có sự khác biệt rất lớn giữa các phiên bản gốc (Vanilla v1.0, v1.22) và vô số bản Mod. Việc ghi chép từ diễn đàn hoặc bộ nhớ cá nhân dễ dẫn đến thông tin sai lệch. Bài học này hướng dẫn bạn dựng khung dữ liệu chuẩn xác để tự trích xuất dữ liệu thực tế.

2. CẤU TRÚC BẢNG DỮ LIỆU CHUẨN (10 CỘT THÔNG TIN)

Bạn hãy mở phần mềm Bảng tính (Excel hoặc Google Sheets) và tạo Sheet tên Generals_Database gồm đúng 10 cột sau: 1. General_ID: Mã số định danh của tướng trong file game (VD: 1, 2, 3...). 2. General_Name: Tên tướng (Phiên âm Hán - Việt / Tên gốc trong game). 3. Faction: Phe / Thế lực ban đầu hoặc trạng thái (Tự do / Tướng ẩn / Sự kiện). 4. Base_Force: Chỉ số Vũ lực gốc chưa qua trang bị. 5. Base_Intellect: Chỉ số Trí lực gốc chưa qua trang bị. 6. Unique_Skills: Võ tướng kỹ / Quân sư kỹ đặc biệt ban đầu. 7. Spawn_Condition: Điều kiện xuất hiện (Năm, Thành trì, Tướng ẩn yêu cầu mã gọi hoặc sự kiện). 8. Data_Type: Phân loại bản game (Bản gốc Vanilla hay Bản Mod cụ thể). 9. Verification_Source: Đường dẫn file dữ liệu gốc (VD: Setting/General.ini) hoặc phương pháp test. 10. Confidence_Score: Mức độ tin cậy (100% - Đã kiểm tra file/in-game; 50% - Cần đối soát lại).

3. PHƯƠNG PHÁP TRÍCH XUẤT DỮ LIỆU TỪ GAME

Cách 1: Trích xuất từ file cấu hình game (Độ tin cậy: Cao nhất)

  • Mở thư mục cài đặt Tam Quốc Quần Anh Truyện VII trên máy tính.
  • Tìm thư mục Setting (hoặc mở file nén dữ liệu Data.pak / Patch.pak bằng công cụ giải nén Pak nếu game nén file).
  • Mở file General.ini bằng Notepad hoặc Notepad++.
  • Cấu trúc tiêu chuẩn trong file:
  • No: Mã ID tướng.
  • Name: Tên tướng.
  • Str: Vũ lực cơ bản.
  • Int: Trí lực cơ bản.

Cách 2: Kiểm chứng trực tiếp In-Game bằng lệnh Cheat/Test

  • Tại màn hình đại lục, gõ chuỗi usecheat để bật chế độ test.
  • Nhập lệnh gọi tướng theo ID để xác minh tướng ẩn/tướng thường có tồn tại trong phiên bản bạn đang chơi hay không.

4. QUY TRÌNH XỬ LÝ KHOẢNG TRỐNG DỮ LIỆU

  • Nếu chưa mở được file .ini hoặc chưa test được in-game đối với một tướng ẩn cụ thể, đánh dấu cột Confidence_Score là Chờ kiểm chứng và để trống cột chỉ số. Tuyệt đối không tự điền chỉ số dựa trên cảm tính hoặc trí nhớ.

Đầu ra cần nộp

1 File Bảng tính (Excel hoặc Google Sheets) chứa bảng cấu hình 10 cột, đã điền hoàn chỉnh dữ liệu kiểm chứng của ít nhất 10 tướng (gồm tướng thường và tướng ẩn/mã ID) trích xuất trực tiếp từ bản game hiện có.

Checklist hoàn thành

  • [ ] Bảng tính có đủ 10 cột thông tin theo chuẩn thiết kế.
  • [ ] Đã điền ít nhất 10 tướng từ bản game thực tế đang cài trên máy.
  • [ ] Tất cả các dòng dữ liệu đều có ghi rõ đường dẫn file nguồn hoặc lệnh test và mức độ tin cậy.

Cần bạn xác nhận trước Day tiếp theo

  • Bạn đang cài đặt phiên bản game nào (Bản gốc v1.0/v1.22 hay một bản Mod cụ thể như Bảo Đao, Tố Phong)?
  • Thư mục game trên máy bạn có hiển thị rõ file Setting/General.ini hay dữ liệu đang bị đóng gói trong file .pak?

Hình minh họa nên có: Mô tả cấu trúc bảng dữ liệu Excel chuẩn và quy trình đối soát từ file General.ini vào bảng tính.
